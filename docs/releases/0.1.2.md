# noface 0.1.2

Footnotes and the library fixed in places you'd notice, and noface made ready for more
Kindles: every size on screen is now a physical length, so the interface is laid out
the same on any screen, and each release carries one zip per Kindle it's been tested on.

## Fixed

- **Footnotes:** a tap between two notes' marks, on one line or one above the other,
  opens the one you tapped nearer, where it could open the line above's. A word
  carrying two notes' marks shows both raised and small, and each opens its own note,
  where the second was drawn as plain text and couldn't be opened.
- **Library:** the sort button is round like search and stats, and says the order it
  sorted by as it changes, so the row of tabs fits on every Kindle. The filter tabs are
  sized to their labels. A tap in the gap between two covers opens the nearer one.
- **Library search:** a space typed at the end of a search shows in the field, where it
  drew nothing until the next letter.
- **Toolbar:** the clock sits level with the icons, on the same line as the page's
  own clock.
- **Changing the text:** if a book can't be laid out again after a change to the text
  size or typeface, it keeps your place as the pages last showed it, rather than going
  back to where you were when you opened it.
- **Scrubber and search:** the scrubber's bar no longer peeks out beside its knob near
  the start of a book, and an empty search field's cursor sits before its placeholder.
