# noface 0.3.0

Know how long a book has left, right from the home screen, and trust noface with your
reading: a place, a note or a setting is never lost to a drive that failed a read, and
when something can't be saved, noface tells you instead of pretending.

## New

- **Time left on the home screen.** The Continue reading card says how far you are and
  how long the book has left at your own pace ("62% read · 3 h 20 min left"), learned
  from how fast you actually read. Aa > More > "Show time left" turns it off.
- **Two books of one name, kept apart.** Each book's place, notes, page breaks and
  cover now go by its whole path, so the same file name in two folders no longer
  shares them. The first start moves your files to their new names, once.
- **noface says when it couldn't save.** If the drive won't take your place, the
  library tells you as the book closes ("Your place couldn't be saved."), and the book
  tells you as it opens when its place can't be read; marking a book read or unread
  says so when the mark couldn't be kept.

## Better

- **Long books open.** An EPUB with tens of thousands of paragraphs takes about a third
  less memory, so very long omnibus editions that showed "This book can't be opened
  here." now open.
- **The page never waits on the Kindle.** Telling the Kindle you're still reading,
  and switching Wi‑Fi off while you read, no longer hold up a page turn when the
  Kindle's own services are slow to answer.
- **Every highlight, every time.** A book's highlights and bookmarks are read from
  the Kindle however many there are, a note the Kindle's sync changes meanwhile is
  never shown twice or missed, and a database busy with a sync is waited for rather
  than read as no notes.
- **A dictionary download finishes** even if you put the Kindle down: it's kept
  awake until the download is done.

## Fixed

- A place, settings, reading speed or reading stats there on the drive but unreadable
  for a moment are never written over with fresh ones; noface waits until it can read
  them.
- Marking a book read from a filtered page of the library no longer stops noface.
- An EPUB with an empty author, or tags that close themselves (`<i/>`, `<a/>`), opens.
- A word with a character that isn't valid text keeps its place on the page instead
  of vanishing.
- An EPUB whose links or file names have a `#` written as `%23` opens.
- Locking while running mode's pause card is up keeps running paused.
- Plugging into a computer still hands the Kindle over when the USB watcher had died.
- If noface fails to start on three boots in a row, starting with the Kindle turns
  itself off as it should, even when the drive won't take the setting at first.

## Updating from 0.2.0

Copy the new **noface** folder over the old one, as always. On its first start noface
moves your books' files to their new names and lays out each book's pages again once,
the next time you open it; your places, notes and stats are kept. Backing up the
**noface-data** folder first costs nothing.
